# Sistema de Cadastro de Clientes em Python

## Sobre o projeto
Sistema desenvolvido em Python para gerenciar clientes pelo terminal.

## Funcionalidades
- Cadastrar clientes
- Listar clientes
- Pesquisar clientes
- Editar clientes
- Excluir clientes
- Validar nomes e telefones
- Impedir telefones duplicados
- Gerar relatórios
- Exportar clientes para CSV
- Importar clientes de CSV
- Salvar dados em JSON

## Tecnologias utilizadas
- Python
- JSON
- CSV

## Como executar
1. Instale o Python.
2. Abra a pasta do projeto no terminal.
3. Execute:

python cadastro_clientes_v6.py
